# Results

The release preserves only compact reference evidence. The formal LS-PMPC S5B result is 13.060586% lower paired mean tip RMS, 19.859454% lower UAV x-RMSE, 59/60 tip wins, and zero primary safety failures over 60 paired evaluations. Historical primary solve-time P95 was 1.0731 ms; timing varies with hardware.

The S6T2 Task-LQR baseline improved calm position and orientation metrics, acquired the calm setpoint at 2.455 s, improved crosswind orientation, worsened crosswind position by 6.328867%, and did not acquire the crosswind target.
