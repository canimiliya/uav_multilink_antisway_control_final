## Decision B

`KEEP_BENCHMARK_V1_1_REVISE_COMPETENCE_GOVERNANCE`

The mission envelope remains physically defensible, but the v1 70% overall gate conflates normal-operational eligibility with advanced robustness. Governance v2 therefore separates nominal competence from challenge differentiation while preserving all physical benchmark content.

Root-cause classification:

- Mission envelope: not the structural root cause.
- Competence governance: primary root cause.
- Traditional class: contributing limitation under strong disturbance and multi-link coordination.
- Controller implementation: contributing limitation, but not a sufficient explanation for the governance mismatch.

This decision does not pass any controller. The post-freeze retrospective found 0/3 existing Traditional methods eligible under v2. P2-R1R1 remains `BLOCKED_P2_TRADITIONAL_COMPETENCE`; P2-R1R2 remains `P2_NATIVE_TRADITIONAL_RECOVERY_FAILED`.

No new controller run is authorized. A future qualification requires a separately authorized task, new protocol freeze, and new Development run. SATC, Paper, Equal-Rate, and Holdout remain not run.
