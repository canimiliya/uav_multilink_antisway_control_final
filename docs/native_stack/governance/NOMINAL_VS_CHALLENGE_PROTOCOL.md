# Native Benchmark nominal/challenge role protocol

## Frozen identity-preserving partition

This protocol changes no case identity, signal, wind realization, task, metric, endpoint success definition, plant, or actuator limit. It assigns research roles to the existing 200 Development cases:

- **Nominal cohort (100):** calm, moderate constant 1.5 m/s, and zero-mean stochastic wind with 0.8 m/s scale. These represent normal operational competence.
- **Challenge cohort (100):** 3 m/s strong sustained, 3 m/s strong transient, and ramp-to-3 m/s wind. These deliberately test advanced disturbance rejection and transient coordination.

Both cohorts contain 50 setpoint and 50 smooth-trajectory cases. The classification was frozen from mission intent and wind physics, not from which controller won.

## Research roles

Traditional methods must establish a reliable, safe, real-time comparison object in nominal operation. They must remain safe over all 200 cases, but their challenge success is reported as robustness evidence rather than used as a survival qualification.

Advanced methods earn their scientific value by improving strong-wind, transient, ramp, and multi-link coordination results without sacrificing nominal usability or all-case safety.

This separation prevents challenge failure from automatically erasing an otherwise valid baseline while preserving every difficult case as comparison evidence.
