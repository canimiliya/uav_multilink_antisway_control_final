# Native Benchmark v1.1 to v1.2-governance

`native-stack-benchmark-v1.2-governance` is a governance-only platform freeze based directly on `native-stack-benchmark-v1.1`.

Unchanged:

- plant and model hash;
- actuator authority and `WrenchCommand` interface;
- Development and Holdout identities and semantic fingerprints;
- reference, wind, case resolver, metrics, success definition, and SafetyV2;
- Holdout execution prohibition.

Added:

- nominal/challenge research-role definition;
- Traditional eligibility v2;
- governance-only tests and documentation.

Excluded from the clean platform branch:

- R1R1/R1R2 controllers, searches, and performance artifacts;
- diagnostic oracle implementation and results;
- retrospective pass/fail evidence;
- SATC and Paper work.

The tag certifies the same physical benchmark with a revised governance protocol. It does not certify any baseline or authorize P2-R2.
